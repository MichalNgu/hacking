# FTP (21 / 2121)

## 🔍 1. Enumerace služby

FTP (File Transfer Protocol) běží standardně na:

|Port|Použití|
|---|---|
|21|FTP Control Channel|
|20|Data Channel (aktivní FTP)|
|2121|Alternativní FTP port|

FTP používá oddělený kanál:

```
Client
  |
  | TCP 21 (Commands)
  |
FTP Server
  |
  | TCP 20 (Data)
  |
Files
```

---

# 🛰️ Nmap Enumerace

Základní sken:

```
nmap -sC -sV -p 21,2121 <IP>
```

Hledání všech FTP skriptů:

```
nmap --script ftp-* -p 21 <IP>
```

Užitečné NSE skripty:

|Skript|Účel|
|---|---|
|ftp-anon|Test anonymního přístupu|
|ftp-syst|Získání systému|
|ftp-banner|Banner grabbing|
|ftp-brute|Brute-force|

Příklad:

```
nmap --script ftp-anon,ftp-syst -p21 <IP>
```

# 🌀 8. FTP Bounce Attack

Starší FTP servery umožňovaly zneužití příkazu:

```
PORT
```

Útočník:

```
Attacker
    |
    |
 FTP Server
    |
    |
Internal Server
```

FTP server funguje jako proxy.

Použití:

```
nmap -b anonymous:password@ftp.server <target>
```

Využití:

- skenování interní sítě
- obcházení firewallů

Moderní servery:

```
port_promiscuous=NO
```

mají ochranu zapnutou.

# 🔐 10. FTP přes TLS (FTPS)

Klasické FTP:

```
USER
PASS
```

je posíláno nešifrovaně.

FTPS používá TLS:

```
FTP + SSL/TLS
```

Kontrola:

```
openssl s_client -connect <IP>:21 -starttls ftp
```
